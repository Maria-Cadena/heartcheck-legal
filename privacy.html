2. Qué es HeartCheck

HeartCheck es una aplicación móvil y web de apoyo al autocuidado personal y familiar orientada al registro manual de mediciones de presión arterial, pulso, hábitos diarios (hidratación, actividad física, sueño, estado emocional y rutinas), recordatorios de medicación, estudios médicos y localización de establecimientos de salud.

3. Datos que recopila y procesa HeartCheck

  • Datos de cuenta y autenticación: nombre, correo electrónico, credenciales protegidas gestionadas por Supabase Auth o identificadores de sesión OAuth 2.0 / OpenID Connect (por ejemplo, Google o Facebook Login con los permisos mínimos public_profile y email).
  • Registros de salud y bienestar: mediciones ingresadas por el usuario (presión sistólica, diastólica, pulso y notas), recordatorios de medicación, citas médicas, estudios adjuntos y hábitos diarios.
  • Fotografías y avatares: imágenes que el usuario elige voluntariamente para su foto de perfil o estudios médicos, almacenadas de forma privada en el bucket heartcheck-estudios de Supabase Storage bajo políticas de acceso por usuario.
  • Ubicación opcional: coordenadas obtenidas únicamente cuando el usuario autoriza el permiso de ubicación para centrar el mapa de centros médicos o consultar calidad del aire local.

4. Almacenamiento local (SQLite) y en la nube (Supabase)

HeartCheck utiliza una arquitectura Offline-First con base de datos local SQLite en el dispositivo y sincronización con Supabase PostgreSQL protegida mediante políticas de seguridad a nivel de fila (Row Level Security — RLS), de modo que cada usuario autenticado solo puede acceder a sus propios registros y perfiles autorizados.

5. Finalidad y uso de la información

Los datos se utilizan exclusivamente para brindar las funciones de seguimiento personal dentro de HeartCheck. HeartCheck no vende datos personales ni de salud ni los comparte con redes publicitarias.

6. Derechos del usuario y eliminación de datos

Puedes editar o eliminar mediciones, hábitos, recordatorios, estudios y fotografía directamente dentro de la aplicación, o solicitar la eliminación completa de tu cuenta siguiendo las instrucciones en Eliminación de Datos.
